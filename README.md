# Project Description
This project is an audit of the open-source software Git. It explores its origin, license, ethical aspects, role in the Linux ecosystem, and comparison with proprietary alternatives. The project also includes five shell scripts demonstrating practical Linux skills.

---

# Shell Scripts 

# Script 1 — System Identity Report
This script displays system information such as kernel version, user, uptime, and Linux distribution of the system on which it is running.

# Script 2 — FOSS Package Inspector
This checks whether Git is installed on the system and displays version details along with a brief description.

# Script 3 — Disk and Permission Auditor
This script checks the important system directories by checking their permissions and disk usuage by the Git.

# Script 4 — Log File Analyzer
This script analyzes a log file by reading it line by line and counts how many times a specific keyword, which we want to check appears. It also displays few of the last matching lines.

# Script 5 — The Open Source Manifesto Generator
This script generates a personalized open-source manifesto based on user input and combines the information into a paragraph and saves it into a text file.
